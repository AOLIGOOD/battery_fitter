# Battery Fitter — 电池适配计算器 & 3D 可视化

给定电池仓尺寸和单节电池参数，自动计算最优排列方案，判断能否满足目标电压/容量需求，并提供 **3D/2D 可视化**。

支持两种运行方式：
- **CLI** (`battery_fitter.py`) — 命令行交互式输入 + Matplotlib 3D 视图
- **Web App** (`battery_fitter_app.py`) — 浏览器 Dash 应用，滑块实时调整 + Plotly 交互式 3D

## 功能特性

- 🔋 **三种排列策略** — 单一方向、混合方向、分层铺设，自动选取最优
- 🛡 **PCB 保护板** — 自动扫描电池暴露面，体素化 + 积分图搜索最佳贴附位置
- 📐 **绝缘材料分析** — 提取暴露面连通区域，计算绝缘片数量和面积
- 📊 **BOM 导出** — 一键导出材料清单 CSV（电池、保护板、绝缘片 + 成本）
- 🎨 **3D/2D 可视化** — 电池仓线框 + 电池实体 + 保护板高亮 + 绝缘片叠加
- 💾 **参数预设** — 保存/加载常用配置（Web App）
- ⚡ **电压 + 容量** — 同时考虑串联(S)和并联(P)需求

## 快速开始

### 环境要求

```bash
pip install numpy matplotlib plotly dash
```

### CLI 版本

```bash
# 交互式输入
python battery_fitter.py

# 运行内置示例（18650 4S + 保护板）
python battery_fitter.py --example

# 仅文本输出，不显示图表
python battery_fitter.py --no-gui
```

### Web App 版本

```bash
python battery_fitter_app.py
# 浏览器打开 → http://127.0.0.1:8050
```

拖动左侧滑块实时调整参数，3D 视图即时更新。支持鼠标旋转/缩放/平移。

## 排列策略

### 1. 单一方向 (Single)
所有电池朝向一致，适合规则长方体电池仓。

### 2. 混合方向 (Mixed)
沿某个轴分两段，每段使用不同电池方向。适合仓尺寸与电池尺寸不整除的情况。

### 3. 分层铺设 (Layered)
沿堆叠轴 DP 求最优层组合，每层可使用不同朝向。适合需要最大化空间利用的场景。

## PCB 保护板放置

程序通过 **体素化 + 积分图** 算法在电池暴露面上搜索保护板可放置位置：

1. 构建 2D 占据网格（电池投影 → 可用，阻挡电池 → 障碍）
2. 填充面电池包围盒（PCB 可跨接缝隙）
3. 用积分图 O(1) 检测每个候选矩形窗口
4. 按贴附面积降序排列，优先用 PCB 最大面贴合

## 参数说明

| 参数 | 单位 | 说明 |
|------|------|------|
| Compartment L/W/H | mm | 电池仓内部尺寸 |
| Margin | mm | 仓壁内衬间隙（双侧扣除） |
| Battery L/W/H | mm | 单节电池外形尺寸 |
| Battery Gap | mm | 电池间安装间隙（pitch 间距） |
| Battery V/Ah | V / Ah | 单节电池标称电压和容量 |
| Target V/Ah | V / Ah | 目标总电压和总容量 |
| PCB L/W/H | mm | 保护板尺寸（设 0 跳过） |
| PCB Gap | mm | 保护板安装间隙 |

## 计算公式

```
串联数 S = ceil(目标电压 / 单节电压)
并联数 P = ceil(目标容量 / 单节容量)
最少电池 = S × P

空间利用率 = (电池总体积) / (有效仓容积) × 100%
```
